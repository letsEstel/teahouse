# 怎么读这本书

这本书和茶馆的代码是同一批文件。

书的文字直接写在 `.rs` 代码文件里，以 `//|` 开头。编译器把这些行当注释跳过，所以同一个文件，编译器读到的是程序，你读到的是一章书。你现在看到的是用 `scripts/bind-book.py` 装订出来的阅读版：它只调整排版，不增加也不删减内容。

所以书里有三样东西：

- **文字**：讲这段代码在做什么，为什么这样做，顺带讲 Rust 这门语言。
- **代码**：真实的代码，一行不少，顺序和文件里一样。不是摘录，不会过时。
- **标着“运行过”的例子**：这些例子写在代码的文档注释里，`cargo test` 每次都会运行。例子的结果要是和书上说的不一样，测试就会失败。

## 让它跑起来

装好 [Rust](https://rustup.rs) 和 git 以后，在仓库根目录运行：

```sh
cargo test -p teahouse-core    # 运行第一批法则的测试，和书里的例子
./scripts/demo.sh              # 开一间茶馆，走一遍允许和拒绝
```

`demo.sh` 在你的电脑上开一个临时的 Relay，然后让几个人依次试各种写入。下面是其中几步的真实输出：

```text
▌ 3. 伙计直接添加成果
  ✓ 伙计推送成功

▌ 4. 伙计想给自己升成老板
  ✗ 被拒绝（符合预期）· refused, as it should be

▌ 5. 茶客想直接写 main
  ✗ 被拒绝（符合预期）· refused, as it should be

▌ 9. 连老板也不能改写历史
  ✗ 被拒绝（符合预期）· refused, as it should be
```

这本书要讲的，就是这些“被拒绝”是怎么发生的。下一章从那张决定一切的表开始。
