# 怎么读这本书

这本书写给三种读者。先找到自己，从对应的地方开始。

| 你是 | 从哪里开始 | 可以跳过 |
|---|---|---|
| 从没写过程序 | 第一部分 从零开始 | 什么都别跳 |
| 写过程序，第一次学 Rust | 第二部分 Rust 速通 | 第一部分 |
| 熟悉 Rust，要维护这个项目 | 第三部分 茶馆的架构 | 第一、第二部分 |

每一部分的开头都有一个小测验。拿不准的话，做一下就知道该不该跳。

读完第一部分，你能看懂并写出简单的程序。读完第二部分，你能读懂茶馆的 Rust 代码。第三部分讲茶馆是怎么运转的，以及怎么自己做 hook 这样的设计。

## 书里的代码块

这本书里的代码都真的运行过。`cargo test` 会运行每一段代码，再检查结果和书上印的一样。

- 普通的代码，后面常常跟着它的**运行结果**。
- 标着**这段故意编译不过**的代码是有意的：你迟早会遇到这样的报错，书里先带你看一遍。
- 标着**摘自**某个文件的代码，是茶馆真实代码的原文。代码一改，书的检查就会失败，所以它不会过时。

每节末尾有**练习**。先自己做，做完再点开答案对照。

术语第一次出现时带着英文，书后有一张中英术语表。这个行业的文档和报错都是英文的，早点把两边对上，以后省很多事。

请亲手打代码，再运行一遍。只读是学不会的，打错了也没关系，看懂报错正是要学的本领。

## 卡住了怎么办

把报错再读一遍，它通常写明了问题在哪一行。如果某一节你反复读也读不懂，那多半是这本书没写好，请告诉我们。
