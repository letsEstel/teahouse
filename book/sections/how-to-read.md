# 怎么读这本书

这本书写给从没写过程序的人。读完以后，你能用 Rust 写程序，能维护茶馆这个项目。

## 一次一小节

每一节只讲一件新东西，只用前面讲过的东西。一节读完大约十五分钟。

请不要只是读。学编程和学骑车一样，看别人骑学不会。每一节里的代码都请亲手打一遍，再运行一遍。打错了也没关系，看懂报错正是要学的本领。

## 书里的三种代码块

这本书里的代码都真的运行过。`cargo test` 会运行每一段代码，再检查结果和书上印的一样。

一段普通的代码，后面常常跟着它的**运行结果**。

有些代码标着**这段故意编译不过**。这是有意的：你迟早会遇到这样的报错，书里先带你看一遍。

每节末尾有**练习**。先自己做，做完再点开答案对照。

## 卡住了怎么办

卡住很正常。把报错再读一遍，它通常写明了问题在哪一行。如果某一节你反复读也读不懂，那多半是这本书没写好，请告诉我们。
