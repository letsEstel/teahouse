# Names

**English** · [中文](NAMES.zh.md) · [Deutsch](NAMES.de.md)

A few modules have nicknames. Folders and files in the code keep their plain names; the nicknames appear only in the module’s first comment, in the documentation and in the book, never in the interface.

| Nickname | Module |
|---|---|
| Xixia Stele (西夏碑) | Translation: `app/src/i18n/`, the key check `app/scripts/i18n-check.mjs` |
| Dayun Dawn Bell (大云晓钟) | Notifications (not written yet, problem 0026) |
| Horse Treading on a Flying Swallow (马踏飞燕) | Networking: sync, offline, reconnecting (`client/src/sync.rs`, `transport.rs`, `app/src/api/autosync.ts`) |
| Yunxiang (云翔) | Links between houses: many houses along one street (not built yet, section 2 of the spec) |
| Walnut Garden (核桃园) | The examples: `app/src/data/` and demo mode in the app. The ones inside are tea stalls; the stalls are not real, the real ones are rooms in a house |
| Xiaobei Street (小北街) | The seventh tea stall in the Walnut Garden: `app/src/data/xiaobei.ts` |
